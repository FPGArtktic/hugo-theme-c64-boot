Upstream: https://github.com/google/fonts/tree/main/ofl/pressstart2p
Upstream commit: e06fe11c39051bddaef73ec338a9d1c8175723f1

The bundled WOFF2 was produced from the upstream TTF by REPACKAGING ONLY
(woff2_compress; no glyph, table or metadata changes). Per OFL-FAQ 2.2.1 a
format conversion is not a Modified Version, so the Reserved Font Name is kept.

would forbid use of the Reserved Font Name. Integrity hashes: fonts.sha256.
