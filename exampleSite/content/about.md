## Why a C64 screen

This site is a tribute to the Commodore 64 — to the machine that printed
`READY.` and then waited.

It did not suggest anything, it did not phone home, and it did not need a
megabyte of JavaScript to show forty columns of text. It switched on in a
second, it told you exactly how much memory you had left, and when it could
not find a file it said so in four words. A whole generation learned what a
computer was from a screen that did nothing until you typed.

So the homage here is not nostalgia for the look. It is the rest of it: the
page is the screen, the navigation is the disk directory with real block
counts, the errors are the errors the machine actually printed, and nothing is
fetched from anywhere else. A small argument that the pattern still works.
